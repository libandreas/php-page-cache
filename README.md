# PHP Page Cache: Cache, βελτιστοποίηση εικόνων και πλοήγηση SPA

## Πρόσθετο επίπεδο βελτιστοποίησης

Τα εργαλεία λειτουργούν ως πρόσθετο επίπεδο βελτιστοποίησης πάνω στην υπάρχουσα ιστοσελίδα (application overlay layer). Επεξεργάζονται το παραγόμενο περιεχόμενο και προσθέτουν cache, βελτιστοποίηση εικόνων και διαδραστική πλοήγηση, χωρίς να απαιτείται αντικατάσταση της πλατφόρμας.

Η ιδιαίτερη τεχνική κατεύθυνση είναι ο συνδυασμός αυτών των λειτουργιών πάνω σε διαφορετικές εφαρμογές PHP. Στο παρελθόν έχουν γίνει προσπάθειες ενσωμάτωσης σε παραγωγικά custom sites και σε WordPress. Η ενεργοποίηση και οι διαδρομές των modules προσαρμόζονται στην κάθε εγκατάσταση.

Εργαλεία για ταχύτερη φόρτωση σελίδων PHP, σταθερότερη διάταξη και διαδραστική πλοήγηση. Περιλαμβάνει ενσωμάτωση cache και εικόνων ως WordPress plugin.

## Cache σελίδων
Το `ttfb.php` αποθηκεύει το παραγόμενο HTML ανά URL και το σερβίρει μέχρι να λήξει η cache. Το `ttfb.js` ζητά μόνο τα εργαλεία του floating container από τον χειριστή `render_ttfb_tools()`. Σε ανεξάρτητη εγκατάσταση το αίτημα πηγαίνει στο `ttfb.php`, με `ttfb-tools=1` και `page` τη διαδρομή της σελίδας μαζί με τις παραμέτρους της. Στο WordPress χρησιμοποιείται το `admin-ajax.php?action=ttfb_tools`. Δεν ξαναφορτώνει τη σελίδα στο παρασκήνιο και δεν ενημερώνει το υπόλοιπο DOM.

Το `#floating-tools-div` δημιουργείται με τον υπάρχοντα έλεγχο σύνδεσης και τις συναρτήσεις εργαλείων της συγκεκριμένης σελίδας. Τα links διατηρούν τη διαδρομή και τις παραμέτρους της. Τα προσωπικά κουμπιά δεν αποθηκεύονται στην κοινή cache και η απόκριση των εργαλείων έχει `Cache-Control: private, no-store`. Αν το αίτημα αποτύχει, καταγράφεται σφάλμα στην κονσόλα χωρίς ανανέωση του περιεχομένου.

## Επιλεκτική cache περιεχομένου
Το ttfb-elements.php επαναχρησιμοποιεί το HTML τμημάτων με κλάσεις cache-element-1 έως cache-element-4. Αντικαθιστά τα αντίστοιχα τμήματα πριν εκτελεστεί η υπόλοιπη σελίδα, περιορίζοντας την επανάληψη εργασιών μέσα σε αυτά. Η cache βασίζεται στη διαδρομή URL χωρίς query parameters. Δεν αποτελεί γενική cache ερωτημάτων βάσης δεδομένων.

## Βελτιστοποίηση εικόνων
Τα cls.php και cls.js δεσμεύουν χώρο πριν φορτωθούν οι εικόνες, εφαρμόζουν lazy loading και δημιουργούν μικρογραφίες με cache. Στοχεύουν σε μικρότερες μετακινήσεις περιεχομένου και αποδοτικότερη φόρτωση εικόνων.

## Πρόσθετο πλοήγησης SPA
Τα spa.php και spa.js προσθέτουν διαδραστική πλοήγηση σε σελίδες PHP. Φορτώνουν εσωτερικές σελίδες και φόρμες μέσω AJAX, ενημερώνουν το υπάρχον DOM και τη διεύθυνση στον browser χωρίς πλήρη ανανέωση. Η συμπεριφορά των scripts κάθε εφαρμογής χρειάζεται προσαρμογή στην ενσωμάτωση.

## Ανανέωση εκδόσεων πόρων
Το auto-version.php προσθέτει έκδοση στα τοπικά CSS και JavaScript βάσει του χρόνου τροποποίησης, ώστε οι ενημερώσεις να μη μένουν πίσω από παλιές εκδόσεις στην cache του browser.

## Ενσωμάτωση
Τα modules βρίσκονται στο common/ και χρησιμοποιούν τα functions.php και polyfills.php. Το ttfb-cls.php φορτώνει την cache σελίδων και τη βελτιστοποίηση εικόνων στο WordPress. Τα SPA, fragment cache και auto-version ενσωματώνονται ξεχωριστά στην αρχικοποίηση της εφαρμογής και δεν ενεργοποιούνται αυτόματα από το WordPress plugin.

Το WordPress plugin καταχωρίζει το AJAX action `ttfb_tools` για συνδεδεμένους και μη συνδεδεμένους επισκέπτες. Ο χειριστής χρησιμοποιεί το φορτωμένο περιβάλλον του WordPress για τον έλεγχο διαχειριστή. Η διεύθυνση του script και του αιτήματος εργαλείων γράφεται στο HTML από την εγκατάσταση, ώστε να λειτουργεί και όταν το plugin βρίσκεται μέσα στο `wp-content/plugins/`.

Η cache καταγράφει ποια modules εργαλείων έχουν φορτωθεί στη σελίδα. Το ξεχωριστό αίτημα επαναχρησιμοποιεί μόνο τα αντίστοιχα callbacks. Το CLS παρέχει το `setup_cls_links()` για το κουμπί του, χωρίς επεξεργασία εικόνων. Τα προαιρετικά modules `content-0.php`, `content-1.php` και `simple-file-manager.php` δεν περιλαμβάνονται σε αυτό το project· αν ενσωματωθούν από άλλη εφαρμογή, χρειάζονται τον έλεγχο `TTFB_TOOLS_ONLY` πριν από το εκτελέσιμο τμήμα τους, όπως τα ενημερωμένα αντίγραφα στα προγνωστικά.

## Ελληνικά άρθρα και demo

Η λειτουργία της cache είναι **full-page caching με ξεχωριστή φόρτωση των floating εργαλείων**. Το αποθηκευμένο περιεχόμενο παραμένει σταθερό μετά τη φόρτωση. Το demo εικόνων παρουσιάζει **space reservation για μείωση του Cumulative Layout Shift (CLS)** μαζί με **lazy loading** και παραγωγή thumbnails στον server. Η [δέσμευση χώρου με διαστάσεις εικόνας](https://web.dev/articles/optimize-cls/) και η αναβολή φόρτωσης είναι διαφορετικές τεχνικές που συνδυάζονται.

Ορίστε τη ρίζα αυτού του project ως document root σε έναν PHP server. Τα παραδείγματα λειτουργούν ανεξάρτητα από το WordPress. Για τις εικόνες απαιτείται η επέκταση GD. Η PHP χρειάζεται δικαιώματα εγγραφής στη ρίζα για τα αρχεία ρυθμίσεων και στον φάκελο `cache/`, τον οποίο δημιουργούν τα modules.

- `/demo-cache.php`: άρθρο για τη γρήγορη αρχική εμφάνιση δυναμικών σελίδων, με προσομοίωση αργού query τριών δευτερολέπτων, δοκιμαστικά αποτελέσματα και συνδέσμους ενεργοποίησης της cache. Δεν απαιτεί βάση δεδομένων, CSS ή πρόσθετο JavaScript του demo. Στη νέα λειτουργία, το `ttfb.php` εισάγει το `ttfb.js`, το οποίο εκτελεί GET στο `ttfb.php?ttfb-tools=1&page=...` και ενημερώνει μόνο το floating container.
- `/demo-images.php`: μεγάλο άρθρο για τη σταθεροποίηση εικόνων, με έξι γενικές φωτογραφίες από το [Lorem Picsum](https://picsum.photos/) αποθηκευμένες τοπικά στον φάκελο `demo-images/`, απλά inline grids και συνδέσμους ενεργοποίησης του CLS. Περιλαμβάνει μόνο το `cls.php`, ώστε η page cache να μην επηρεάζει τη σύγκριση. Το module εισάγει το δικό του `cls.js`. Οι φωτογραφίες χρησιμοποιούν τα Picsum IDs 10, 15, 29, 54, 16 και 28 αντίστοιχα.

Στην πρώτη επίσκεψη με ενεργή cache και χωρίς αποθηκευμένο αντίγραφο, η αργή εργασία εκτελείται πριν εμφανιστεί το HTML. Στο επόμενο άνοιγμα της ίδιας διεύθυνσης επιστρέφεται το αποθηκευμένο HTML. Η ώρα και τα αποτελέσματα παραμένουν όπως αποθηκεύτηκαν. Το αίτημα για τα floating εργαλεία δεν ξανατρέχει τη σελίδα ή το query του demo. Όταν λήξει η cache, το επόμενο κανονικό άνοιγμα δημιουργεί νέο αντίγραφο, με προεπιλεγμένο διάστημα λήξης 48 ωρών. Ο εμφανιζόμενος χρόνος εργασίας δεν αποτελεί μέτρηση του TTFB.

Τα queries της σελίδας εκτελούνται κατά τη δημιουργία του αντιγράφου. Σε μια περιοχή μελών, το κοινό αποθηκευμένο HTML παραμένει ανώνυμο. Ο έλεγχος σύνδεσης στο ξεχωριστό αίτημα καθορίζει μόνο τα floating εργαλεία και δεν μετατρέπει το cached περιεχόμενο σε προσωπική σελίδα. Το demo χρησιμοποιεί αποκλειστικά δημόσια, δοκιμαστικά αποτελέσματα.

Τα TTFB, SPA και CLS είναι απενεργοποιημένα από προεπιλογή και ενεργοποιούνται μόνο ανά σελίδα. Οι διακόπτες αλλάζουν τη ρύθμιση της συγκεκριμένης διαδρομής, ανεξάρτητα από τα query parameters, και ισχύουν για όλους τους επισκέπτες της. Δεν υπάρχουν διακόπτες ALL ούτε αναγνώσεις των παλιών αρχείων `urls-cache-all.txt`, `urls-spa-all.txt` και `urls-cls-all.txt`. Οι μεμονωμένες ενεργοποιήσεις αποθηκεύονται στα `urls-cache-enabled.txt`, `urls-spa-enabled.txt` και `urls-cls-enabled.txt` αντίστοιχα.

Για τη σύγκριση CLS, χρησιμοποιήστε περιορισμό ταχύτητας δικτύου και απενεργοποιήστε την cache του browser από τα εργαλεία ανάπτυξης. Ανοίξτε τη σελίδα με και χωρίς σταθεροποίηση και παρατηρήστε τις παραγράφους καθώς φορτώνουν οι εικόνες. Τα μεγάλα αρχεία από μόνα τους δεν εγγυώνται αργή φόρτωση. Δεν έχει προστεθεί τεχνητή καθυστέρηση στο plugin. Το CSS δεν επιβάλλει ύψος ή `aspect-ratio`, ώστε ο δεσμευμένος χώρος να προκύπτει από τις διαστάσεις που προσθέτει το CLS.

Χρειάζονται εγγράψιμη cache, λειτουργίες εικόνων PHP και κατάλληλος έλεγχος διαχειριστή. Οι διαδρομές JavaScript και thumbnails πρέπει να αντιστοιχούν στην εγκατάσταση. Επιλέξτε τη στρατηγική cache ανά σελίδα πριν συνδυάσετε full-page και fragment cache. Οι λειτουργίες στοχεύουν σε βελτιώσεις σχετικές με το PageSpeed, χωρίς εγγυημένη βαθμολογία.
